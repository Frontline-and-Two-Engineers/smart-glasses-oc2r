# Smart Glasses OC2R — Документация

Аддон для **OpenComputers II: Modern (OC2R)** на **NeoForge 1.21.1** с 3 уровнями умных очков (2D HUD, чат/курсор, 3D AR), 3-уровневым радаром сущностей, беспроводной сетью с ретрансляторами, безопасной загрузкой с Pastebin/GitHub и предзагруженными тестовыми дискетами.

## Содержание

1. **[Архитектура кода мода](architecture.md)** — устройство проекта, пакеты, сеть, интеграция с OC2R, рендер, миксин, энергия и Curios.
2. **[Справочник API](api-reference.md)** — все RPC-методы `glasses_bridge`, `radar`, `wireless_card`, `pastebin`, события, координаты и конфиг `smartglasses-common.toml`.
3. **[Примеры программ для OC2R](examples.md)** — готовые скрипты на Lua и MicroPython (HUD, кнопки `H`, чат-бот `$$`, 3D AR-сканер `G`, радар + AR, беспроводная сеть и загрузка с Pastebin/GitHub).

## Быстрый старт в игре

### 1. Очки и мост
1. Скрафтите **Мост умных очков** (`smartglasses:glasses_bridge`) и **Умные очки** нужного уровня (`Ур. 1`, `Ур. 2` или `Ур. 3`).
2. Подключите мост к компьютеру OC2R через **Bus Cable**.
3. Нажмите **ПКМ** очками по мосту для привязки и наденьте очки в слот шлема (или слот `head` в Curios).

### 2. Карты расширения и периферия
- **Карта беспроводной сети (`wireless_card`)** и **Карта Pastebin и GitHub (`pastebin_card`)** вставляются в слоты карт расширения компьютера.
- **Беспроводной ретранслятор (`wireless_repeater`)** ставится в мире и подключается к FE-энергии; автоматически ретранслирует пакеты.
- **Радар сущностей (`radar_tier_1/2/3`)** подключается к компьютеру по **Bus Cable** и появляется как устройство `radar`.

### 3. Проверка устройств в Linux (OC2R)
```sh
export LUA_PATH="/mnt/builtin/lib/lua/?.lua"
lsdev.lua
```
В списке устройств появятся подключённые `glasses_bridge`, `radar`, `wireless_card`, `pastebin`.

### 4. Использование тестовых дискет из креатив-меню
1. Возьмите любую тестовую дискету во вкладке **Smart Glasses OC2R** и вставьте её **ПКМ** в **Disk Drive** (`oc2r:disk_drive`).
2. В Linux смонтируйте дискету:
   ```sh
   mkdir -p /mnt/floppy
   mount /dev/vda /mnt/floppy   # или /dev/vdb, если уже подключён жёсткий диск
   cd /mnt/floppy && ls -la
   lua test_hud.lua
   ```
3. Перед извлечением дискеты обязательно отмонтируйте её:
   ```sh
   cd / && umount /mnt/floppy
   ```

> **Приватность координат:** по умолчанию (`relativeCoordinates = true`) все координаты, возвращаемые `glasses_bridge` и `radar`, **относительны** (считаются от блока моста или радара).
