# Smart Glasses OC2R

Аддон для **OpenComputers II: Modern (OC2R)** на **Minecraft 1.21.1 (NeoForge)**, добавляющий 3 уровня умных очков (HUD, чат/курсор, 3D AR), 3-уровневый радар сущностей, беспроводную сетевую карту с энергозависимым ретранслятором, безопасную карту Pastebin/GitHub и предзагруженные тестовые дискеты.

## Возможности

### Умные очки (3 уровня) и Мост (`glasses_bridge`)
* **Уровень 1 (`smart_glasses`)**: базовый 2D HUD на виртуальной сетке `1920×1080` (прямоугольники, текст, прогресс-бары, иконки предметов, живые графики, 9 точек привязки `Anchor`).
* **Уровень 2 (`smart_glasses_tier_2`)**: 2D HUD + **кликабельный курсор** (клавиша `H`) + **чат-команды** (`$$...`) и ответы через `sendMessage`.
* **Уровень 3 (`smart_glasses_tier_3`)**: 2D HUD + чат и курсор + **3D AR в мире** (маркеры с дистанцией, 3D-линии, рамки на сущностях) + **сканер взгляда** (клавиша `G`).
* **Телеметрия игрока:** `getPlayerStats` (HP, голод, броня, координаты, биом, время суток, заряд).
* **Выживание и интеграции:** крафт-рецепты, опциональное потребление FE-энергии и мягкая поддержка **Curios API** (слот `head`).

### Новые устройства и карты расширения
* **Радар сущностей (3 уровня, `radar`)**:
  * **Уровень 1**: радиус до `64` блоков — `uuid`, `type`, `distance`.
  * **Уровень 2**: радиус до `128` блоков — + `hp`, `maxHp`.
  * **Уровень 3**: радиус до `256` блоков — + `name`, `isPlayer`, `x`, `y`, `z`.
* **Беспроводная сетевая карта (`wireless_card`) и Ретранслятор (`wireless_repeater`)**:
  * Передача сообщений по портам в радиусе действия; адресная отправка `send()` поддерживает как полный UUID, так и **короткий префикс** (например `"7c571a5f"`).
  * **Беспроводной ретранслятор** питается от **FE-энергии** и автоматически пересылает пакеты по цепочке (до 4 хопов), расширяя радиус сети.
* **Безопасная карта Pastebin и GitHub (`pastebin`)**:
  * Загружает raw-текст/скрипты по HTTPS **только** с `pastebin.com`, `raw.githubusercontent.com` и `gist.githubusercontent.com` с защитой от SSRF, редиректов, таймаутов, лимитом размера и кулдауном.
* **Приватность координат (`relativeCoordinates = true` по умолчанию)**:
  * Все координаты в `glasses_bridge` и `radar` по умолчанию **относительные** (отсчитываются от блока моста/радара), чтобы игроки не могли узнать абсолютные мировые координаты при отключённом F3.
* **Тестовые дискеты в креатив-меню**:
  * 5 цветных предзагруженных дискет (`HUD и AR`, `Беспроводная сеть`, `Радар`, `Pastebin и GitHub`, `Всё в одном`) с готовыми Lua-скриптами и `ext2`-образом.

## Быстрый пример на Lua (OC2R)

```lua
local devices = require("devices")
local g = assert(devices:find("glasses_bridge"))

g:clear()
g:addRect("bg", 20, 20, 320, 90, 0x99101820)
g:addItemIcon("ico", 32, 32, "minecraft:diamond", 1.0)
g:addText("title", 75, 38, "OC2R Smart Glasses", 0xFF00E5FF, 1.0)
g:addProgressBar("bar", 32, 75, 290, 16, 75, 100, 0xFF55FF55, 0xFF22303C)
```

## Сборка из исходников

Требуется **JDK 21**:

```bash
./gradlew build
```

Для запуска клиента в среде разработки:

```bash
./gradlew runClient
```
