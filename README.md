# Smart Glasses OC2R

Аддон для **OpenComputers II: Modern (OC2R)** на **Minecraft 1.21.1 (NeoForge)**, добавляющий умные очки с 2D HUD, 3D AR-разметкой в мире и двусторонним взаимодействием с Linux внутри виртуальной машины RISC-V (в духе *OpenPeripherals Terminal Glasses* для 1.7.10).

## Возможности

* **2D HUD (виртуальная сетка `1920×1080`):** прямоугольники, текст, прогресс-бары, иконки предметов (`ItemStack`), живые графики/спарклайны и 9 точек привязки (`Anchor`).
* **3D AR в мире:** плавающие маркеры с дистанцией, 3D-линии навигации и динамические рамки, привязанные к сущностям по UUID.
* **Кликабельный HUD:** клавиша `H` открывает прозрачный курсор поверх экрана — клики по виджетам с `clickable = true` отправляются в OC2R.
* **Сканер взгляда (Gaze Raycast):** клавиша `G` отправляет в компьютер координаты блока или UUID сущности, на которую смотрит игрок.
* **Чат-команды (`$$`):** сообщения в чате с префиксом `$$` перехватываются и передаются в Linux-программу; скрипт может отвечать игроку в чат через `sendMessage`.
* **Телеметрия игрока:** `getPlayerStats` (HP, голод, броня, координаты, биом, время суток, заряд).
* **Выживание и интеграции:** крафт-рецепты, опциональное потребление FE-энергии и мягкая поддержка **Curios API** (слот `head`). Очки не отображаются поверх головы игрока при надевании.

## Быстрый пример на Lua (OC2R)

```lua
local devices = require("devices")
local g = assert(devices:find("glasses_bridge"))

g:clear()
g:addRect("bg", 20, 20, 320, 90, 0x99101820)
g:addItemIcon("ico", 32, 32, "minecraft:diamond", 1.0)
g:addText("title", 75, 38, "OC2R Smart Glasses", 0xFF00E5FF, 1.0)
g:addProgressBar("bar", 32, 75, 290, 16, 75, 100, 0xFF55FF55, 0xFF22303C)
```

## Сборка из исходников

Требуется **JDK 21**:

```bash
./gradlew build
```

Для запуска клиента в среде разработки:

```bash
./gradlew runClient
```
